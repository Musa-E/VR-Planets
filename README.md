# VR Planets   

**By:** Musa Elqaq   
**Unity Version:** `2022.3.45f1`   

----

## Project Description:   

The goal of this project is to have someone be able to look (maybe walk in the future) around different planets.

What I currently have in mind:   
    - [ ] Mars like area where the player can see the type of environment Mars would look like   
    - [ ] A "From-Space" view of different planets, like the Earth or Mars   
    - [ ] A Ringed planet, such as Saturn   
    - [ ] Perhaps a Black Hole, though this may have rather intense graphic issues
